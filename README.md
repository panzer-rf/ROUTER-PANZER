# ROUTER-PANZER

Juego web en HTML5 llamado **Soldado Hacker: Guerra en la Nube**, donde controlas a un soldado cibernético que defiende infraestructura cloud y redes contra virus, malware y ataques DDoS.

## Controles
- `←` y `→`: mover al soldado.
- `Espacio`: disparar firewall.
- `Q`: activar escudo Zero-Trust temporal.
- `E`: lanzar pulso anti-malware para limpiar proyectiles enemigos.

## Objetivo
Sobrevive oleadas crecientes de amenazas y consigue la mayor puntuación posible.

## Ejecución
Abre `index.html` en tu navegador.
